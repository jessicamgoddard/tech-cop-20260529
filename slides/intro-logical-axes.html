Concept: logical directions

Logical properties use block, inline, start, and end instead of top/right/bottom/left, so layouts adapt to any writing direction automatically.

In horizontal left-to-right writing: block = vertical axis, inline = horizontal axis. With writing-mode: vertical-rl, the axes swap; logical properties follow automatically.
